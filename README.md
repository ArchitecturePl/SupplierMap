# SupplierMap

A mapping and data visualization project named **SupplierMap**, originally designed and generated with Claude.

## 📂 Project Structure

Based on the repository layout, the project contains the following core components:
* `index.html` – The main application entry point and interface.
* `mini-map.js` – Script handling map rendering and navigation logic.
* `support.js` – Supporting utility functions and helper modules.
* `data.json` – The dataset containing supplier information and map coordinates.

---

## 📥 Getting Started (First-Time Setup)

If you have not yet downloaded the project or cloned the repository on your local machine, follow these steps:

### 1. Download the Project from Claude
1. Open your chat session with Claude where **SupplierMap** was created.
2. Download the generated project files or code artifacts directly from Claude onto your computer.
3. Create a new folder on your computer and place the downloaded files inside it.

### 2. Clone the Repository (If connecting to GitHub)
If you already created a repository for **SupplierMap** on GitHub and want to link your local folder to it:
1. Open your terminal or command prompt.
2. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/SupplierMap.git
   ```
3. Move your downloaded files from Claude into this newly cloned `SupplierMap` directory.

## 🔄 How to Update the Project

When you generate or download an updated version of **SupplierMap** from Claude in the future, follow these steps to update your local repository and push the changes to GitHub:

1. **Replace Files:** 
   Download the latest project files from Claude and place them into your local **SupplierMap** repository folder, replacing the older versions.

2. **Open Terminal / Command Prompt:**
   Navigate to your project directory:
   ```bash
   cd path/to/SupplierMap
   ```

3. **Check Status:**
   See which files have been modified or added:
   ```bash
   git status
   ```

4. **Stage Changes:**
   Add all modified and new files to the staging area:
   ```bash
   git add .
   ```

5. **Commit Changes:**
   Save the snapshot with a descriptive commit message:
   ```bash
   git commit -m "Update SupplierMap with latest version from Claude"
   ```

6. **Push to GitHub:**
   Upload your updates to your remote repository:
   ```bash
   git push origin main
   ```
   *You may be asked to confirm your identity / log in to github, just follow their instructioins and do so.*
